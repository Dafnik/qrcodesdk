## Add Core to a framework project

The React, Vue, Svelte, and Angular packages depend on Core. They re-export:

- shape and center-image factories
- `automaticSegmenter`
- types

They do **not** re-export `qrcode()`, `QRCodeError`, or the [payload helpers](/reference/payloads/).
Add Core as a direct dependency when you need those, or when Next.js Server Components import style
factories from `@qrcodesdk/core/style`. Your app can only import packages it declares.

Install the same Core version your framework package uses:

1. Run `npm ls @qrcodesdk/core` or `pnpm why @qrcodesdk/core`. Note the version listed under your
   framework package, such as `@qrcodesdk/react`.
2. Install exactly that version with `npm install --save-exact @qrcodesdk/core@<version>` or
   `pnpm add --save-exact @qrcodesdk/core@<version>`.
3. Run the first command again. It should list a single Core version.

Repeat these steps whenever you upgrade the framework package.

Matching versions keep a single copy of Core installed. With two copies:

- shapes from one copy can draw incorrectly in the other,
- renderers ignore center images created by the other copy,
- `instanceof QRCodeError` fails.

## Module format

Every QRCodeSDK package is ES modules only. There is no CommonJS build.

| Your code                          | How to load QRCodeSDK                                    |
| ---------------------------------- | -------------------------------------------------------- |
| ES modules, TypeScript, bundlers   | `import`                                                 |
| CommonJS on Node.js 22.12 or newer | `require()` or dynamic `import()`                        |
| CommonJS on older Node.js          | Dynamic `import()`; `require()` throws `ERR_REQUIRE_ESM` |

A dynamic `import()` works in CommonJS on every supported Node.js version:

```js
// CommonJS module, such as index.cjs
async function main() {
  const {QRCodeSVGRenderer, qrcode} = await import('@qrcodesdk/core');
  console.log(qrcode('https://qrcodesdk.dev').render(QRCodeSVGRenderer()));
}

main();
```

TypeScript with `module: 'commonjs'` rewrites `import()` to `require()`. Use `module: 'node16'` or
`'nodenext'` to keep the dynamic import. See
[Core runtime compatibility](/packages/core/#runtime-compatibility).
