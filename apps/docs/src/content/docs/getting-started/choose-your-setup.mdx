Choose the smallest package set that produces the output your application needs. Core is the default
when SVG or terminal text is enough; renderer and framework packages build on it.

## Add Core to a framework project

The React, Vue, Svelte, and Angular packages install `@qrcodesdk/core` as their own dependency and
re-export its shape factories, center-image factories, `automaticSegmenter`, and types. They do not
re-export `qrcode()`, `QRCodeError`, or the [payload helpers](/reference/payloads/). To use those,
or to import style factories from `@qrcodesdk/core/style` in Next.js Server Components, add Core as
a direct dependency. Your application can only import packages it declares.

Install the exact Core version that your framework package depends on:

1. Run `npm ls @qrcodesdk/core` or `pnpm why @qrcodesdk/core` and note the version under your
   framework package, such as `@qrcodesdk/react`.
2. Install that exact version with `npm install --save-exact @qrcodesdk/core@<version>` or
   `pnpm add --save-exact @qrcodesdk/core@<version>`. Replace `<version>` with the version from
   step 1.
3. Run the first command again. It should list a single Core version.

Matching versions let the package manager install one copy of Core. With two copies, shapes from one
copy can draw incorrectly in the other, renderers ignore center images created by the other copy,
and `instanceof QRCodeError` fails. Repeat these steps whenever you upgrade the framework package.

## Module format

Every QRCodeSDK package is published as ES modules only. There is no CommonJS build. Use `import` in
ES modules, TypeScript, and bundled applications.

CommonJS code on Node.js 22.12 or newer can `require()` the packages, because these Node.js versions
load ES modules from `require()`. On older Node.js versions, `require()` throws `ERR_REQUIRE_ESM`.
Load the package with a dynamic `import()` instead, which works in CommonJS on every supported
Node.js version:

```js
// CommonJS module, such as index.cjs
async function main() {
  const {QRCodeSVGRenderer, qrcode} = await import('@qrcodesdk/core');
  console.log(qrcode('https://qrcodesdk.dev').render(QRCodeSVGRenderer()));
}

main();
```

TypeScript projects that compile to CommonJS rewrite `import()` to `require()` with
`module: 'commonjs'`. Use `module: 'node16'` or `'nodenext'` to keep the dynamic import, as
[Core runtime compatibility](/packages/core/#runtime-compatibility) describes.
