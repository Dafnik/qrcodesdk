## Choose a browser output

| Choose | Package              | Return value        | Best fit                                                       |
| ------ | -------------------- | ------------------- | -------------------------------------------------------------- |
| SVG    | `@qrcodesdk/core`    | `string`            | Scalable inline markup and the recommended browser default     |
| Image  | `@qrcodesdk/browser` | `HTMLImageElement`  | A DOM image with `alt` text, backed by PNG, WebP, GIF, or JPEG |
| Canvas | `@qrcodesdk/browser` | `HTMLCanvasElement` | Drawing, compositing, pixel access, or manual PNG export       |

Start with SVG unless the next browser API specifically needs an Image or Canvas element. SVG stays
sharp when resized and does not require Canvas support. Image and Canvas output require both
`@qrcodesdk/core` and `@qrcodesdk/browser`.

:::note[Client-side rendering]
Create Image and Canvas renderers only after browser DOM APIs are available. In a server-rendered
application, run them after hydration or use the runtime-neutral SVG renderer on the server.
:::

## SVG string

`QRCodeSVGRenderer` returns complete SVG markup. It is not a DOM node, so insert it into an existing
element or pass it to your browser-side template.

### Insert it into the DOM

Insert the SVG into a container as inline markup:

```ts
import {QRCodeSVGRenderer, qrcode} from '@qrcodesdk/core';

const svg = qrcode('https://qrcodesdk.dev').render(
  QRCodeSVGRenderer({
    accessibility: {ariaLabel: 'Scan to open qrcodesdk.dev'},
  }),
);

const container = document.querySelector('#qrcode');

if (container) {
  container.innerHTML = svg;
}
```

```html
<div id="qrcode"></div>
```

The renderer escapes label text
and image URL attributes; it encodes the payload as modules rather than inserting it as text.
Do not concatenate unescaped user input into the SVG or its surrounding HTML. For center images,
validate uploaded image content before converting it to a data URL; `svgCenterImage()` checks the
URL format but does not inspect the embedded image.

### Include it in browser-generated markup

The returned string can be interpolated into HTML generated by a browser-side template:

```ts
import {QRCodeSVGRenderer, qrcode} from '@qrcodesdk/core';

const svg = qrcode('https://qrcodesdk.dev').render(
  QRCodeSVGRenderer({
    accessibility: {ariaLabel: 'Scan to open qrcodesdk.dev'},
  }),
);

const html = `
  <section>
    <h2>Scan this QR code</h2>
    ${svg}
  </section>
`;
```

Apply layout styles to the inserted root SVG through its container:

```css
#qrcode > svg {
  display: block;
  width: min(100%, 20rem);
  height: auto;
}
```

## Image element

The Image element renderers synchronously return a new `HTMLImageElement` whose `src` contains the
rendered image as a data URL. Use them when the QR code should behave like an ordinary image in the
DOM. Pick the renderer by the encoded format:

| Renderer                  | Entry point               | Encoded format                                                        |
| ------------------------- | ------------------------- | --------------------------------------------------------------------- |
| `QRCodePNGImageRenderer`  | `@qrcodesdk/browser/png`  | PNG, encoded natively by the browser                                  |
| `QRCodeWebPImageRenderer` | `@qrcodesdk/browser/webp` | Lossless WebP, usually the smallest file                              |
| `QRCodeGIFImageRenderer`  | `@qrcodesdk/browser/gif`  | GIF with 256 colors and binary transparency                           |
| `QRCodeJPEGImageRenderer` | `@qrcodesdk/browser/jpeg` | Lossy JPEG on a solid matte color, for destinations that require JPEG |

Each format has its own entry point, so a bundle only includes the encoder it imports. WebP, GIF,
and JPEG use encoders bundled in the SDK and produce the same bytes in every browser, including
Safari, which cannot encode WebP natively. The bundled JPEG encoder also blends transparent pixels
onto a white matte, where the browser's own JPEG encoding would turn them black. All four accept the
same options. See the [Image element renderers reference](/reference/renderers/image/) for the format differences.

### Insert and style it

```ts
import {QRCodePNGImageRenderer} from '@qrcodesdk/browser/png';
import {qrcode} from '@qrcodesdk/core';

const image = qrcode('https://qrcodesdk.dev').render(
  QRCodePNGImageRenderer({
    accessibility: {
      alt: 'QR code for qrcodesdk.dev',
      ariaLabel: 'Scan to open qrcodesdk.dev',
      title: 'QR code for qrcodesdk.dev',
    },
  }),
);

image.className = 'qrcode';
document.querySelector('#qrcode')?.append(image);
```

```html
<div id="qrcode"></div>
```

```css
.qrcode {
  display: block;
  width: min(100%, 20rem);
  height: auto;
}
```

### Use the data URL

Read `src` when another browser API needs the encoded image rather than the element:

```ts
import {QRCodePNGImageRenderer} from '@qrcodesdk/browser/png';
import {qrcode} from '@qrcodesdk/core';

const image = qrcode('https://qrcodesdk.dev').render(QRCodePNGImageRenderer());
const response = await fetch(image.src);
const png = await response.blob();

await navigator.clipboard.write([
  new ClipboardItem({
    'image/png': png,
  }),
]);
```

The Clipboard API requires a secure context and may require a user gesture or permission. Browsers
reliably accept only `image/png` on the clipboard, so use the PNG renderer here.

## Canvas element

`QRCodeCanvasRenderer` synchronously returns a new `HTMLCanvasElement`. Use Canvas when code needs
to draw onto the output, combine it with other graphics, inspect pixels, or export it manually.

### Insert it into the DOM

Give the Canvas its own accessible name, then append it wherever the QR code should appear:

```ts
import {QRCodeCanvasRenderer} from '@qrcodesdk/browser';
import {qrcode} from '@qrcodesdk/core';

const canvas = qrcode('https://qrcodesdk.dev').render(
  QRCodeCanvasRenderer({
    style: {moduleSize: 8, quietZone: 4},
    accessibility: {ariaLabel: 'Scan to open qrcodesdk.dev'},
  }),
);
document.querySelector('#qrcode')?.append(canvas);
```

```html
<div id="qrcode"></div>
```

### Draw it into another Canvas

Use the QR Canvas as a source for a larger composition:

```ts
import {QRCodeCanvasRenderer} from '@qrcodesdk/browser';
import {qrcode} from '@qrcodesdk/core';

const qrCanvas = qrcode('https://qrcodesdk.dev').render(QRCodeCanvasRenderer());
const target = document.querySelector<HTMLCanvasElement>('#target');
const context = target?.getContext('2d');

if (target && context) {
  target.width = qrCanvas.width;
  target.height = qrCanvas.height;
  context.drawImage(qrCanvas, 0, 0);
}
```

## Replace a rendered QR code

Each render creates a new string or element. When the payload changes, render again and replace the
old output so the container does not accumulate QR codes:

```ts
import {QRCodePNGImageRenderer} from '@qrcodesdk/browser/png';
import {qrcode} from '@qrcodesdk/core';

const container = document.querySelector('#qrcode');

export function updateQRCode(payload: string) {
  const image = qrcode(payload).render(
    QRCodePNGImageRenderer({accessibility: {alt: '', ariaLabel: `Scan to open ${payload}`}}),
  );

  container?.replaceChildren(image);
}
```

If application state changes frequently, render again only when the payload or options change. In
React, Vue, Svelte, or Angular, you can use the framework components instead.

## Keep browser output reliable

- Keep the default four-module quiet zone clear of nearby text, borders, and other UI.
- Give meaningful SVG, Image or Canvas output an accessible label.
- Use CSS to shrink output responsively, but do not enlarge Image or Canvas output beyond its
  rendered pixel dimensions. Increase `style.moduleSize` when more raster resolution is needed.
- Scan-test the final page at its smallest supported viewport and after any CSS transforms, browser
  zoom, screenshots, or image compression.
