title: Serve a QR code
description: Return SVG strings or PNG Buffers from HTTP handlers with the correct content type.

---

Server handlers can return an SVG string from `@qrcodesdk/core` or a PNG `Buffer` from
`@qrcodesdk/node`. This page will own the shared response patterns for both outputs.

Compare their return types in [Renderer outputs](/reference/renderers/).
