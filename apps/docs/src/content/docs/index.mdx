## Install Core

<PackageManagerTabs packages={['@qrcodesdk/core']} mode="add" />

Render a scalable SVG string with the runtime-neutral Core package:

```ts
import {QRCodeSVGRenderer, qrcode} from '@qrcodesdk/core';

const svg = qrcode('https://qrcodesdk.dev').render(QRCodeSVGRenderer());
```

SVG is the recommended default for most user-facing QR codes: it stays sharp at any size and works
in browsers, servers, email, and static assets. See the [SVG renderer reference](/reference/renderers/svg/)
when you need its options or exact return contract.

## Choose by runtime and output

| Where will it run?               | Output you need                                    | Start here                                 |
| -------------------------------- | -------------------------------------------------- | ------------------------------------------ |
| Any supported JavaScript runtime | SVG or terminal text strings                       | [`@qrcodesdk/core`](/packages/core/)       |
| Browser DOM                      | Canvas, PNG-backed Image element, or file download | [`@qrcodesdk/browser`](/packages/browser/) |
| Node.js-compatible runtime       | PNG `Buffer` for files or responses                | [`@qrcodesdk/node`](/packages/node/)       |
| React or Next.js                 | SVG, Image, or Canvas component                    | [`@qrcodesdk/react`](/packages/react/)     |
| Angular                          | SVG, Image, or Canvas component                    | [`@qrcodesdk/angular`](/packages/angular/) |
| Terminal, shell script, or CI    | Terminal text, SVG file, or PNG file               | [`@qrcodesdk/cli`](/packages/cli/)         |

[Choose your setup](/getting-started/choose-your-setup/) for the matching install command, or compare
every built-in return type in [Renderer outputs](/reference/renderers/).
