QRCodeSDK, [qrcode](https://github.com/soldair/node-qrcode),
[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator), and
[qr-code-styling](https://github.com/kozakdenys/qr-code-styling) all generate standard QR codes.
They differ in how they split runtimes, which outputs they ship, and how far styling goes.
