A QR code is a grid of small squares called modules. The three large squares in its corners are
finder patterns. They help scanners locate and orient the code. Other reserved patterns help a
scanner read the grid and identify its encoding settings.

The remaining modules hold the payload and error-correction data. The encoder groups this data into
bytes called codewords, then places their bits in a zigzag path through the grid. Some QR code sizes
need extra remainder bits to fill that path.
