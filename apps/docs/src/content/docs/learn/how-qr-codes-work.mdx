A QR code combines reserved functional modules with placed codeword bits. Some versions also need a
few remainder bits to complete the placement path. Configure a symbol, then hover or focus any
module to see which region it belongs to. Click, tap, or press <kbd>Enter</kbd> to pin a selection.
