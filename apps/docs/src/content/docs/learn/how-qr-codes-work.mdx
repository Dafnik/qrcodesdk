A QR code is more than a black-and-white grid. Its modules carry orientation targets, format
metadata, encoded payload bits, padding, and Reed–Solomon error correction. Configure a symbol,
then hover or focus any module to see its role. Click, tap, or press <kbd>Enter</kbd> to pin a
selection.
