`@qrcodesdk/core` generates QR matrices, SVG strings, and terminal text without browser or Node.js
APIs. Custom renderers can turn its matrices into other formats.

## Install

<PackageManagerTabs packages={['@qrcodesdk/core']} mode="add" />

## Quick start

```ts
import {QRCodeSVGRenderer, qrcode} from '@qrcodesdk/core';

const svg = qrcode('https://qrcodesdk.dev').render(QRCodeSVGRenderer());
```

The result is an SVG `string`. See the [SVG renderer reference](/reference/renderers/svg/) for its
options and constraints.

## What Core adds

| Capability                    | API                        | Return type    |
| ----------------------------- | -------------------------- | -------------- |
| Generate a QR matrix          | `qrcode(payload).matrix()` | `QRCodeMatrix` |
| Render scalable vector output | `QRCodeSVGRenderer`        | SVG `string`   |
| Render terminal output        | `QRCodeTextRenderer`       | text `string`  |

See [Builder and matrix](/reference/builder/) for accepted payloads, matrix options, builder methods,
and matrix output.

## Style the output

Import shape and pattern factories from `@qrcodesdk/core/style`:

```ts
import {QRCodeSVGRenderer, qrcode} from '@qrcodesdk/core';
import {circle, finder, rounded} from '@qrcodesdk/core/style';

const svg = qrcode('https://qrcodesdk.dev').render(
  QRCodeSVGRenderer({
    style: {
      moduleSize: 8,
      foreground: '#0f172a',
      modules: rounded(),
      finder: finder({ring: rounded({radius: 1}), center: circle(), color: '#e11d48'}),
    },
  }),
);
```

See [Customize appearance](/guides/customize/) for style options and custom shapes.

Typed helpers serialize common application values before generation. See
[Payload helpers](/reference/payloads/) for email, phone, SMS, geographic, and Wi-Fi payloads.

## Runtime compatibility

> `@qrcodesdk/core` supports any JavaScript runtime providing native ESM, ES2020 support, and a global `TextEncoder`.
> It has no Node.js, DOM, filesystem, or framework dependency.

TypeScript projects should use `moduleResolution: 'bundler'`, `'node16'`, or `'nodenext'` to resolve
the package's ESM entry points and subpaths.

| Runtime                         | Support policy                                          |
| ------------------------------- | ------------------------------------------------------- |
| Node.js                         | All maintained LTS lines                                |
| Deno                            | Current stable major                                    |
| Bun                             | Current stable release                                  |
| Browsers                        | Current evergreen browser families                      |
| Other runtimes and edge workers | Native ESM, ES2020, and a global `TextEncoder` required |

For runtime-specific output, add the package for your runtime or framework:

| Package                                    | Use it for                                                           | Return value                                    |
| ------------------------------------------ | -------------------------------------------------------------------- | ----------------------------------------------- |
| [`@qrcodesdk/browser`](/packages/browser/) | Canvas element, PNG, WebP, and GIF Image elements, browser downloads | `HTMLCanvasElement`, `HTMLImageElement`, `void` |
| [`@qrcodesdk/node`](/packages/node/)       | PNG, WebP, and GIF bytes                                             | `Buffer`                                        |
| [`@qrcodesdk/cli`](/packages/cli/)         | Command line generation from terminals and scripts                   | Terminal text, SVG, PNG, WebP, and GIF files    |
| [`@qrcodesdk/react`](/packages/react/)     | React SVG, PNG, WebP, GIF, and Canvas components                     | React element                                   |
| [`@qrcodesdk/vue`](/packages/vue/)         | Vue SVG, PNG, WebP, GIF, and Canvas components                       | Vue component                                   |
| [`@qrcodesdk/svelte`](/packages/svelte/)   | Svelte SVG, PNG, WebP, GIF, and Canvas components                    | Svelte component                                |
| [`@qrcodesdk/angular`](/packages/angular/) | Angular SVG, PNG, WebP, GIF, and Canvas components                   | Angular component                               |

Compare every built-in output in [Renderer outputs](/reference/renderers/).

## Public API

The root exports the builder, renderers, errors, and shared types. For direct ESM imports without a
bundler, use `@qrcodesdk/core/matrix`, `@qrcodesdk/core/svg`, `@qrcodesdk/core/text`, or
`@qrcodesdk/core/error` to avoid loading unrelated renderers. Bundled applications can use root
imports with tree shaking.

Import shape and pattern factories and custom path types from `@qrcodesdk/core/style`. Matrix
types and role names belong to `@qrcodesdk/core/matrix`; payload serializers belong to
`@qrcodesdk/core/payload`. See [Custom renderers](/reference/custom-renderers/) for matrix-based
custom renderer examples.

## Generated output stability

Output is deterministic for one installed implementation, but matrix modules, SVG markup, and PNG,
WebP, and GIF bytes may change between QRCodeSDK releases. Pin exact package versions and keep fixtures when exact
artifacts matter. See the [version and output policy](/project/release-policy/).
