## Matrix generation

The matrix-generation code was adapted from
[LostInBrittany/qr-esm](https://github.com/LostInBrittany/qr-esm), which was based on Kang
Seonghoon's [qr.js](https://github.com/lifthrasiir/qr.js).

## Validation and benchmarks

QRCodeSDK uses these libraries to validate output and compare performance:

- [soldair/node-qrcode](https://github.com/soldair/node-qrcode), published as `qrcode`
- [`qrcode-generator`](https://github.com/kazuhikoarase/qrcode-generator)
- [`qr-code-styling`](https://github.com/kozakdenys/qr-code-styling), for styled SVG benchmarks

The published packages do not depend on them at runtime.
