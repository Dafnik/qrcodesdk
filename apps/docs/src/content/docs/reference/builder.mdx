The builder turns input data into a QR code matrix and passes that matrix to a renderer. See the
[`@qrcodesdk/core` package overview](/packages/core/) for installation and runtime support.

The complete builder and matrix API is documented here as the canonical reference. Detailed option
tables will be consolidated into this page as part of the Core reference split.
