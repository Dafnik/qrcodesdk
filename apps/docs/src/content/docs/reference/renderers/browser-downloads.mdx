---
title: Browser download renderers
description: Reference for browser-only SVG and PNG download wrappers from @qrcodesdk/browser.
docType: reference
---

`@qrcodesdk/browser` provides download wrappers for SVG strings and PNG-backed Image elements. They
trigger a browser download and return `void`.

See the [`@qrcodesdk/browser` package overview](/packages/browser/) while this reference is being
consolidated.
