Every renderer turns the same `QRCodeMatrix` into a different output. Pick the output your
application needs, then install its package.

## Core

`@qrcodesdk/core` runs in any Core-compatible runtime. The text renderer needs a UTF-8 text
environment.

| Output                                      | Renderer             | Returns  | Best for                               |
| ------------------------------------------- | -------------------- | -------- | -------------------------------------- |
| [SVG string](/reference/renderers/svg/)     | `QRCodeSVGRenderer`  | `string` | Scalable web, print, and server output |
| [Terminal text](/reference/renderers/text/) | `QRCodeTextRenderer` | `string` | Terminals, logs, CLIs, and snapshots   |

## Browser

`@qrcodesdk/browser` needs the browser DOM.

| Output                                                            | Renderer                      | Returns             | Best for                                         |
| ----------------------------------------------------------------- | ----------------------------- | ------------------- | ------------------------------------------------ |
| [Canvas element](/reference/renderers/canvas/)                    | `QRCodeCanvasRenderer`        | `HTMLCanvasElement` | Drawing, compositing, and manual raster export   |
| [PNG Image element](/reference/renderers/image/#png)              | `QRCodePNGImageRenderer`      | `HTMLImageElement`  | Accessible DOM images and CSS workflows          |
| [WebP Image element](/reference/renderers/image/#webp)            | `QRCodeWebPImageRenderer`     | `HTMLImageElement`  | The smallest lossless DOM image                  |
| [GIF Image element](/reference/renderers/image/#gif)              | `QRCodeGIFImageRenderer`      | `HTMLImageElement`  | Destinations that require GIF                    |
| [JPEG Image element](/reference/renderers/image/#jpeg)            | `QRCodeJPEGImageRenderer`     | `HTMLImageElement`  | Destinations that require JPEG                   |
| [SVG browser download](/reference/renderers/browser-downloads/)   | `QRCodeDownloadSVGRenderer`   | `void`              | User-triggered SVG downloads                     |
| [Image browser download](/reference/renderers/browser-downloads/) | `QRCodeDownloadImageRenderer` | `void`              | User-triggered PNG, WebP, GIF, or JPEG downloads |

## Node.js

`@qrcodesdk/node` runs in Node.js-compatible runtimes.

| Output                                    | Renderer             | Returns  | Best for                                            |
| ----------------------------------------- | -------------------- | -------- | --------------------------------------------------- |
| [PNG Buffer](/reference/renderers/png/)   | `QRCodePNGRenderer`  | `Buffer` | Files, HTTP responses, email, and attachments       |
| [WebP Buffer](/reference/renderers/webp/) | `QRCodeWebPRenderer` | `Buffer` | The smallest lossless files and responses           |
| [GIF Buffer](/reference/renderers/gif/)   | `QRCodeGIFRenderer`  | `Buffer` | Destinations that require GIF                       |
| [JPEG Buffer](/reference/renderers/jpeg/) | `QRCodeJPEGRenderer` | `Buffer` | Destinations that require JPEG, photo center images |

## Frameworks and custom output

- Framework packages wrap the same outputs in components: [React and Next.js](/packages/react/),
  [Vue](/packages/vue/), [Svelte](/packages/svelte/), and [Angular](/packages/angular/).
- For another return type, write a [custom renderer](/reference/custom-renderers/).
